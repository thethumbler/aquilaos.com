A UNIX-like operating system, written from the kernel up.

AquilaOS is a hobby operating system: a monolithic kernel, a C library and the tools around them, built toward POSIX. It runs on x86-64 and i386, boots in QEMU, and runs dash, bash, curl, X and Doom.

Features

Kernel

  • Monolithic, with processes, threads and kernel threads
  • Sessions, process groups and job control
  • POSIX signals, delivered on return to user mode
  • Copy-on-write, demand paging and mmap
  • APIC with MSI; a clock to the nanosecond from the TSC or HPET

Storage and devices

  • ext2 and minix, read and write; tmpfs, procfs, devfs, devpts
  • Virtual terminals on the framebuffer or VGA text mode
  • ATA disks, PS/2 input, 8250 UART, VESA framebuffer

Network

  • Intel e1000 and e1000e Ethernet
  • IPv4, ARP and ICMP; UDP and TCP (RFC 9293)
  • DHCP client and DNS resolver

User space

  • newlib 4.6, dash, sbase, runit as init
  • About 45 ports: bash, curl with TLS, tcc, Lua, X with dwm and st, Doom

Getting started

Table 1. Build targets, run from a clone of the repository on Linux.
CommandWhat it does
make toolchainBuilds GCC, binutils, newlib and Limine for AquilaOS, once (about 15 minutes)
makeBuilds the kernel, user space and the initrd
make portsBuilds the optional software: bash, curl, X, Doom and the rest
make runBoots it in QEMU, with the console on the serial port
make testRuns the test suite in QEMU
