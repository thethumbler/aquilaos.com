A small UNIX-like operating system, written to be read.

AquilaOS is a kernel, a C library and the tools around them. It's meant to be boring: the kernel does what UNIX kernels have done for decades, the plain way, in code small enough to read in full, with a document for each part of it. It runs on x86 and aarch64, on several CPUs, and runs dash, bash, curl, X and Doom.

Start here

You need gcc, ld, cpio and QEMU, nothing else. In about a minute, make run-min builds the kernel with your gcc and boots it with one tiny program: a shell with no C library, each of its commands a system call or two.

  1. Read the documents, in order: how the kernel boots, takes interrupts, manages memory and processes, and the rest, each with pointers into the code.
  2. Change something: add a command to the tiny shell, or a printk() to a system call, and boot it again.
  3. Debug it: make debug boots the same kernel waiting for gdb, and a panic prints a stack trace.
  4. Test it: make test runs the kernel's test suite in QEMU.
  5. Build the whole system: a cross toolchain, then the C library, the shell, the utilities and the ports.

Features

Kernel

  • Monolithic, with processes, threads and kernel threads
  • SMP: up to 32 CPUs, with one kernel lock
  • Sessions, process groups and job control
  • POSIX signals, delivered on return to user mode
  • Copy-on-write, demand paging and mmap
  • APIC with MSI; a clock to the nanosecond from the TSC or HPET

Storage and devices

  • ext2 and minix, read and write; tmpfs, procfs, devfs, devpts
  • Virtual terminals on the framebuffer or VGA text mode
  • ATA disks, PS/2 input, 8250 and PL011 UARTs, VESA framebuffer

Network

  • Intel e1000 and e1000e Ethernet
  • IPv4, ARP and ICMP; UDP and TCP (RFC 9293)
  • DHCP client and DNS resolver

User space

  • newlib 4.6, dash, sbase, runit as init
  • About 45 ports: bash, curl with TLS, tcc, Lua, X with dwm and st, Nano-X, UnixBench, Doom
